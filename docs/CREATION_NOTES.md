# 创作说明（300 字内）

**选题动机**：备考 408，手写链表、二叉树常"看不懂、不会写"。市面 AI 助手多是"写完再问"，学习被打断，也缺陪伴感。

**核心创意**：反其道而行——"写一行，讲一行"。插件每识别一行代码就在行尾生成中文注释；桌宠实时联动：写码时奔跑、停顿时待机，用气泡把代码讲成大白话，像学伴蹲在桌上陪刷题。

**技术实现**：三合一本地架构——VSCode 插件（29 类 C 规则引擎，零依赖不联网）→ 本地桥接 → Electron 透明桌宠（改造开源）→ AHK 系统开关。全程本地、隐私友好，预留大模型接口。

**收获**：用"拆解需求、复用开源、逐步验证"做出完整可运行的作品，也更懂如何让工具有人情味。
