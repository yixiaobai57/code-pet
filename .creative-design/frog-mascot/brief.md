# 奶蛙桌宠形象 — 设计 Brief

## 主题
将 CodePet 桌宠形象从三花猫替换为「奶蛙」（Milky Frog 风格）：通体黄色、圆胖呆萌、爱笑的卡通青蛙。

## 商品
无实体商品／不适用。核心对象：桌宠角色贴图（应用内 assets 资源）。

## 用途与交付
- 用途：Electron 透明桌宠窗口贴图，替换现有 `assets/mitarashi.webp`（idle）与 `assets/running_cat.webp`（running）。
- 交付：两张透明背景角色图（idle 站立 + running 奔跑），生成后本地转存为透明 PNG/WebP 进应用，打包交付 exe。
- 画幅：1:1 方图（生成），应用内由 CSS 控制显示尺寸（约 120×84 逻辑像素）。

## 形象锁定（角色锚点）
- 物种/身体：通体亮黄色圆胖青蛙，身形矮胖圆润，头身比接近 1:1。
- 肚皮：浅米白色大肚皮区域（腹部浅色块）。
- 四肢：深棕色短小四肢（手/脚深棕）。
- 眼睛：大大的圆眼，眼白明显、绿色瞳孔。
- 表情：呆萌微笑（奶蛙标志性憨笑，嘴张开露齿或弯弯笑线均可，保持呆萌）。
- 材质/风格：扁平 2D 卡通插画风，边缘圆润干净，适合小尺寸展示；与桌宠像素画风可共存于透明窗口。

## 构图
- idle：正面站立呆萌，身体居中，占画面约 80%，无背景、无其他元素，四周留少量安全边。
- running：同一角色奔跑姿态（侧身、前倾、四肢摆动），横向构图，身体居中偏前，占画面约 80%。

## 可见文字
画面不出现任何文字。

## 禁止项
禁止：文字/水印/Logo、复杂背景、地面投影以外的装饰物、其他动物/人物、多余的肢体、扭曲五官、写实毛发质感。

## 验收重点
1. 形象一眼可识别为「黄色圆胖呆萌青蛙」。
2. idle 与 running 是同一个角色（相同配色、脸型、五官结构）。
3. 透明背景（角色外无白底/色块），边缘干净。
4. 小尺寸（约 120px 宽）下五官清晰可辨。

## 工作区
- Canvas Workspace：创建后回填。
- 生成：image_gen 生成 core-ip（idle）；image_edit 基于 core-ip 生成 running。
- 本地输出：code-pet/pet/assets/frog_idle.* / frog_running.*
